Four things we do properly

Every one of these starts at the board. Loads checked, circuits sized, paperwork left on site so the next person can read it.

  1. Solar and battery

    Generation and storage

    Grid-tied and off-grid systems with battery storage, sized to what the house actually draws rather than what the sales sheet says.

  2. EV chargers

    Home and commercial

    Tethered and untethered Type 2 units with dedicated circuit protection, load management and a cable run that reads as part of the building.

  3. Air conditioning

    Supply and install

    Split systems, multi-head and ducted, electrically set up and commissioned. Servicing and repairs on systems already in.

  4. CCTV and security

    Wired and monitored

    IP camera runs, NVR setup and remote viewing, with the recording hardware tucked away rather than hanging off a shelf.

How the job runs

Four steps, same order every time, so nothing gets guessed on the day.

  1. Look and listen

    We walk the site, check the board and the existing circuits, and work out what the job really involves.

  2. Price it straight

    A written quote with the gear, the circuit work and the time. Variations get priced before they are done, not after.

  3. Install and test

    Licensed work to AS/NZS 3000, every circuit tested and tagged, site left clean and the power back on.

  4. Stay reachable

    Certificates and documentation handed over, and a number that answers if something needs a second look.
